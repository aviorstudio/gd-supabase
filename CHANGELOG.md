# Changelog

## 0.0.1
- Initial addon scaffolding.
- `jwt_module` for JWT payload decode and expiry checks.
- `session_store_module` for file-based session persistence and migration.
- `client_id_module` for cross-platform unique client ID management.
- Headless tests for `jwt_module`, `session_store_module`, and `client_id_module`.
